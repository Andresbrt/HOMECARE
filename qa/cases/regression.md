# Casos de prueba de regresión QA HomeCare

## Flujos críticos de negocio
- Registro y login de cliente
- Registro y login de proveedor
- Creación de solicitud de servicio
- Envío de oferta por profesional
- Aceptación de oferta por cliente
- Tracking de servicio en tiempo real
- Chat en tiempo real entre cliente y proveedor
- Pago en sandbox con Mercado Pago
- Historial de servicios
- Notificaciones push / alertas

## Áreas de regresión
- Autenticación y roles
- Gestión de estados del servicio
- Integraciones externas (pagos, notificaciones, almacenamiento)
- Navegación y routing de pantallas
- Manejo de errores (API, forms, validaciones)
- Persistencia de sesión y datos locales

## Checklist de regresión
- [ ] Autenticación cliente y proveedor
- [ ] Creación de solicitud cliente
- [ ] Envío de oferta profesional
- [ ] Aceptación de oferta cliente
- [ ] Actualización de tracking
- [ ] Mensajes de chat enviados y recibidos
- [ ] Flujo de pago sandbox
- [ ] Carga de historial
- [ ] Cierre de sesión y reingreso
